# 激光清洗图片数据处理GUI

## 启动

在 `数据处理` 文件夹内运行：

```powershell
python main.py
```

程序默认把上一级目录作为实验数据目录，并自动预填 `4.Base.jpg`。也可以在界面中点击“选择基材”，通过 Windows 文件选择器选择其他基材图片。

## 主要流程

1. 选择基材图片。
2. 选择单张样品图片，或选择实验图片所在文件夹。
3. 如需避开边缘暗角，点击“框选ROI”，在预览图中拖拽选择区域；不框选时默认按全图计算。
4. 点击“处理当前图片”或“批量处理文件夹”。
5. 在结果表查看 `R/%`、`ΔG/%`，并按需导出 Excel、CSV、掩膜图和叠加图。
6. 批量处理后进入“响应面”页，选择响应值和两个坐标因子，点击“拟合并绘图”。

## 计算公式

残留面积率：

```text
R = 残留像素数 / ROI有效像素数 × 100%
```

程序从基材图的 ROI 建立颜色模型，使用 RGB、HSV、Lab/ΔE 三类判据进行多通道基材颜色过滤。判定为非基材的像素作为残留候选，并经过形态学开闭运算和小连通域过滤。

灰度差：

```text
ΔG = |样品ROI平均灰度 - 基材ROI平均灰度| / 基材ROI平均灰度 × 100%
```

## 响应面分析

程序内置当前实验设计参数：

- `F01-F16`：四因子两水平点。
- `A01-A08`：轴点。
- `M01-M07`：中心点。

响应面使用二次模型：

```text
y = β0 + Σβixi + Σβiixi² + Σβijxixj
```

因子范围：

- `f`: 100-130 kHz
- `τ`: 250-500 ns
- `h`: 0.020-0.030 mm
- `v`: 4000-5000 mm/s

输出包括模型系数、R²、RMSE、二维等高线图、三维响应面图，以及 `R/%`、`ΔG/%` 和等权综合目标的简单最小化结果。

## 输出目录

默认输出到：

```text
数据处理/outputs
```

批量导出的图片位于：

```text
数据处理/outputs/masks
数据处理/outputs/overlays
```
