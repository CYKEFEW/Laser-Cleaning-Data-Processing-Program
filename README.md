# 激光清洗图片数据处理GUI

## 启动

在 `数据处理` 文件夹内运行：

```powershell
python main.py
```

程序默认把上一级目录作为实验数据目录，并自动预填 `4.Base.jpg`。也可以在界面中点击“选择基材”，通过 Windows 文件选择器选择其他基材图片。

## 主要流程

1. 选择基材图片。
2. 导入“图片计算参数表”，用于在结果表中匹配实验编号和工艺参数。
3. 选择单张样品图片，或选择实验图片所在文件夹。
4. 如需避开边缘暗角，点击“框选ROI”，在预览图中拖拽选择区域；不框选时默认按全图计算。
5. 点击“处理当前图片”后会自动切到叠加预览，红色区域为残留判定区域。
6. 可拖动算法参数滑块，释放滑块后自动更新当前图片的评分热力图、掩膜和叠加预览。
7. 默认使用“残留评分算法(推荐)”，可切换到“旧版多通道过滤”对比。
8. 可点击“取基材色”或“取残留色”点选辅助样本；在新算法下，点选颜色只会软抑制或软增强残留评分，不会直接强制整类颜色变红。
9. 点击“批量处理文件夹”处理整批图片。
10. 在结果表查看 `R/%`、`ΔG/%`，并按需导出 Excel、CSV、掩膜图和叠加图。
11. 批量处理后，通过菜单栏“分析 -> 响应面分析”打开独立响应面窗口。

## 菜单栏

- `文件`：选择基材图片、选择单张样品、选择批量文件夹、导入图片计算参数表、导出结果表、退出。
- `处理`：处理当前图片、批量处理文件夹。
- `分析`：打开响应面分析窗口。

## 图片计算参数表

主窗口中计算 `R/%` 和 `ΔG/%` 时，实验参数匹配使用单独的“图片计算参数表”。本文件夹已生成：

```text
数据处理/图片计算-实验参数表_含C组.xlsx
```

这张表用于主窗口结果表中的参数列匹配，和响应面分析窗口导入的参数表分开管理。当前图片计算参数表包含 `F01-F16`、`A01-A08`、`M01-M07` 以及图片目录中存在的 `C01-C05`；其中 `C01-C05` 按中心点参数记录。未导入图片计算参数表时，程序仍会计算 `R/%` 和 `ΔG/%`，但结果表中的 `f/kHz`、`τ/ns`、`h/mm`、`v/(mm/s)` 等参数列为空，并显示未导入/未匹配状态。

图片计算参数表至少需要包含：

- `实验编号`
- `频率f/kHz`
- `脉宽τ/ns`
- `线间距h/mm`
- `扫描速度v/(mm/s)`

程序也兼容英文标准列名：`sample_id`、`f_khz`、`tau_ns`、`h_mm`、`v_mms`。

## 参数预设

程序内置 `图示推荐参数`，并作为启动默认值：

- 算法模式：残留评分算法
- 灵敏度：73
- 局部背景尺度：42 px
- 残留色增强：1.65
- 最小残留面积：2480 px
- 形态学核：3 px
- 叠加透明度：0.27

在“算法参数”区域可以：

- 点击“加载”应用当前选中的预设。
- 点击“保存”把当前算法参数保存为自定义预设。
- 点击“删除”删除自定义预设；内置预设不能删除。

自定义预设保存到：

```text
数据处理/presets.json
```

预设会保存算法模式、滑块参数、基材色样本和残留色样本。预设不保存当前选择的图片或 ROI。

如果已经通过“取基材色”或“取残留色”调出较好的效果，点击“保存”即可把这些取色样本一起保存。下次加载该预设时，界面会恢复对应的基材色/残留色样本数量，并按这些样本参与计算。

## 响应面分析

响应面分析现在在独立窗口中进行。打开方式：

```text
菜单栏 -> 分析 -> 响应面分析
```

使用顺序：

1. 先在主窗口完成单张或批量图片处理，得到结果表中的 `R/%` 和 `ΔG/%`。
2. 在响应面窗口中点击“导入实验编号-参数表”。
3. 选择响应面分析专用参数表，例如本文件夹已生成的：

```text
数据处理/实验编号-参数表.xlsx
```

4. 选择响应值、X因子、Y因子和固定因子值。
5. 点击“拟合并绘图”。

响应面窗口只使用在该窗口中导入的 xlsx 参数表进行编号-参数匹配；不会使用主窗口的图片计算参数表，也不会直接依赖程序内置实验设计。xlsx 至少需要包含以下列：

- `实验编号`
- `频率f/kHz`
- `脉宽τ/ns`
- `线间距h/mm`
- `扫描速度v/(mm/s)`

程序也兼容英文标准列名：`sample_id`、`f_khz`、`tau_ns`、`h_mm`、`v_mms`。

响应面窗口支持图表语言切换：

- 中文：图表和报告使用微软雅黑。
- English：图表和报告使用 Times New Roman。

## 参数调整方法

建议先选基材图和一张代表性样品图，点击“处理当前图片”，再切到“残留评分热力图”和“叠加图”查看效果。热力图越亮表示残留可能性越高；叠加图中的红色区域表示最终被判定为残留的区域。

判断原则：

- 红色区域太多：过滤过严，把部分基材也当成残留。
- 红色区域太少：过滤过松，把部分残留也当成基材过滤掉。
- 合适状态：明显氧化皮/残留区域尽量变红，干净基材区域尽量不变红。

推荐调整顺序：

1. 先调 `灵敏度`：越高，红色残留区域越多；越低，误报越少。
2. 如果边缘暗角或整体照明影响明显，调大 `局部背景尺度`；如果细小纹理被过度平滑，调小该值。
3. 如果明显残留没有变红，点击“取残留色”，在残留/氧化皮位置点选一个或多个样本。
4. 如果干净基材被误判为红色，点击“取基材色”，在误判的干净基材位置点选样本。
5. 如果点错，可分别点击“清除残留色”或“清除基材色”后重新点选。
6. 用 `最小残留面积/px` 和 `形态学核` 去掉小噪点或平滑掩膜。
7. 调到合适后再进行批量处理。

各参数含义：

- `算法模式`：默认“残留评分算法(推荐)”；旧版多通道过滤仅用于对比和回退。
- `灵敏度`：最主要参数。越高，评分阈值越低，红色残留通常越多。
- `局部背景尺度`：用于估计局部背景和消除暗角。数值越大，越偏向忽略大范围照明变化。
- `残留色增强`：控制“取残留色”样本对残留评分的增强强度。越大，点选残留色影响越明显。
- `最小残留面积/px`：用于去掉小噪点，越大，小红点越少。
- `形态学核`：用于平滑掩膜，越大越容易连接或消除细小区域。
- `叠加透明度`：只影响显示，不影响计算结果。

通常先调 `灵敏度`，再用“取残留色”和“取基材色”做局部辅助，最后用去噪和平滑参数整理掩膜。

残留色点选适合用于以下情况：

- 基材颜色和残留颜色比较接近，单靠基材过滤容易漏检残留。
- 某些氧化皮区域没有变红。
- 同一张图中残留有多种颜色，可连续点选多个残留色样本。

基材色和残留色点选都会参与后续单张处理和批量处理；如果更换实验图片类型或点错位置，应先清除对应样本。

## 计算公式

残留面积率：

```text
R = 残留像素数 / ROI有效像素数 × 100%
```

默认算法会在 Lab/HSV 空间中计算连续残留评分，评分来源包括局部变暗、饱和度升高、Lab 色差、蓝紫/氧化色偏移以及相对基材图的异常程度。程序先在基材图上建立误检基线，再按灵敏度生成残留掩膜，并经过形态学开闭运算和小连通域过滤。旧版多通道过滤仍可在界面中手动切换用于对比。

灰度差：

```text
ΔG = |样品ROI平均灰度 - 基材ROI平均灰度| / 基材ROI平均灰度 × 100%
```

## 响应面分析

程序内置当前实验设计参数：

- `F01-F16`：四因子两水平点。
- `A01-A08`：轴点。
- `M01-M07`：中心点。

响应面使用二次模型：

```text
y = β0 + Σβixi + Σβiixi² + Σβijxixj
```

因子范围：

- `f`: 100-130 kHz
- `τ`: 250-500 ns
- `h`: 0.020-0.030 mm
- `v`: 4000-5000 mm/s

输出包括模型系数、R²、RMSE、二维等高线图、三维响应面图，以及 `R/%`、`ΔG/%` 和等权综合目标的简单最小化结果。
